Auto backup (email + Google Drive)

When turned on, the app automatically emails your full data to your Gmail (as an attached file) and also saves a copy in a "MoneyMap Backups" folder in Google Drive. If your phone is lost or broken, you can get your data back.

First-time setup steps (about 3 minutes)

Already set this up before? Replace the code in your script with the new code below, then tap Deploy > Manage deployments > Edit (pencil) > Version: New version > Deploy. The URL stays the same. The new code adds the secret word and the "Restore latest cloud backup" button.

  1. Open script.google.com in a browser, signed in with your Gmail account. Tap New project.
  2. Delete any code that is already there. Copy the code below and paste it there. Then tap the save (disk) icon.
  3. At the top right choose Deploy > New deployment. Using the gear icon, pick the type Web app.
  4. (Recommended) On the second line of the code, type a secret word between the quotes, for example var SECRET = "mango77";. Then type the same word in the "Secret word" box in the app.
  5. Choose Execute as: Me and Who has access: Anyone. Then tap Deploy.
  6. Tap Authorize access and choose your Gmail. If you see "Google hasn't verified this app", tap Advanced > Go to project (unsafe) > Allow. This is your own script, so it is safe.
  7. Copy the Web app URL (https://script.google.com/macros/s/.../exec) and paste it in the box above. Turn on auto backup and save.
  8. Tap Send backup now. The email should reach your Gmail within a few seconds.
